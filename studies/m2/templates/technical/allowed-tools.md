# Allowed tools

You may use an offline text editor, hexadecimal viewer, calculator, and a
general-purpose programming language from the prepared environment. If you
are working as a fixed team, you may discuss the work with your teammates.
Network access, external lookup, retained solutions, and communication with
anyone outside your unit are not allowed during the unit. Do not add a new
teammate after you start.

Save the runnable source, commands and actual output files requested by the
export format. If a prepared tool is missing, use another allowed local tool
where possible and note the problem. Do not replace it with an external service.
