# Maintenance contract

Golden Board is a finished, immutable binary message. Its canonical PNG, TXT and
BIN are exact views of the same 2048 × 2048 cells. The complete budget includes
the bootstrap, five document bodies, inventory, framing/checks and zero reserve.
The message preserves 146 teaching obligations and all 64 complete games.

The implementation uses one Python pipeline, a qualified practical chess adapter,
narrow independent checks and a generic headless JavaScript mechanism. All lesson
frames, feedback, passive routes and complete playback come from the artifact.
The generic mechanism supplies no chess rules, engine analysis or answer service.

Inputs are clean sampled cells or ordered delimited symbols. Primary payload
units occur once. Checks detect faults; they do not vote, correct or guess data.
The exact practical profile and heuristic limits are in [chess](../spec/chess.md),
[predicates](../spec/predicates.md) and [the current grammar](../spec/self-contained-format.md).

Preserve source bytes separately from editorial metadata and derived inputs.
Never silently repair a move or update a qualification hash to hide changed data.
Check critical intermediate states and run proportionate regressions. A changed
message is a separately identified candidate, not a replacement of this final set.

The [guide](guide/README.md) explains the architecture, history and supported
commands. [Status](status.md) and the [verification summary](release/verification.json)
state measured results and their scope. Documentation contains technical findings;
private communications and operational records are not distribution material.
