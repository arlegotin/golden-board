# Guide to Golden Board

Golden Board is both a finished binary message and the machinery used to construct
and check it. The message assumes an intentional clean observation, basic arithmetic,
pattern investigation and programming ability. It does not assume a shared language,
conventional chess notation or a supplied decoder. Whether another intelligence
would understand it remains unknown.

For a first reading, follow **message → bootstrap → format → lessons → games**.
For implementation work, begin with **artifacts → architecture → build**.
For research context, read **origins → decisions → trials**.
