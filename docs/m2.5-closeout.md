## Offline restoration

A source clone supports focused development checks without ignored M2 evidence.
Use the affected focused source/curriculum/content checks for M3; the existing
`scripts/check components` runs all code/component suites without M2 producers.
Historical admission needs the retained candidate, Gate8 tree, pinned transition
archive, acquisition receipt and trial-20 six qualification preimages at the
paths above. Restore these exact files from this retained private checkout or an
exact local backup; a hash/manifest without its bytes is insufficient.

```sh
scripts/check checkpoint
PYTHONPATH=python uv run --locked --offline --no-python-downloads python \
  tools/m2/verify_gate8_v2.py restore-checkpoint --destination /absolute/fresh/path
```

The destination must be absent under a real parent. Restoration uses local Git
and retained evidence only. It installs the original ordinary repository without
new live documentation. It also restores all seven legacy Linux snapshots and
R1/R2 policy owners from the admitted transition tuple, with original modes, so
original component/full/Linux/release runners remain available there. Missing
preimages reject; no acquisition or regeneration occurs implicitly.
Current live full/release rejects presenting historical qualification as a new
current-source result.

`historical-preimage-map.jsonl.gz` maps each compacted historical original path
to a retained exact file or `git:<commit>:<path>`, with length/hash. The original
archive manifest, retained unique files and map permit local reconstruction:
copy retained preimages, read Git preimages with `git show`, restore the manifest’s
directory inventory and the recorded original modes, and verify every original
manifest hash. Do not treat the compacted installed directory as an admitted
full archive or regenerate old production merely to save another small file.
