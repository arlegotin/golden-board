# Project status

The final message contains 4,194,304 binary cells, 146 teaching obligations and
64 complete games with 6890 plies and 6954 anthology states. Canonical PNG/TXT/BIN
identities are recorded in [the artifact manifest](../artifacts/manifest.json).
The default bootstrap uses bounded fields, aligned checksum steps and uniform
single-bit cells. Its document bodies and complete payload retain their identities.

The repository includes offline construction/qualification tools, pinned package
inputs, the inert headless document mechanism, current regression checks, exact
bootstrap illustrations and the [project guide](guide/README.md).

Native tests and reproduction are reported in the
[technical verification summary](release/verification.json). Historical model
results are finite, prior-informed demonstrations with declared assistance and
incomplete original context information. They establish no human learning,
retention or universal comprehension. See [trials](guide/trials.md).

Use `./gb verify` to inspect the canonical set, and follow
[build and development](guide/build.md) for reproduction and source qualification.
