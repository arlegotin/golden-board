# Source Ledger

This ledger contains only sources actually used by the M0 foundation. [`inputs/source-lock.toml`](../inputs/source-lock.toml) is the sole owner of acquired-content hashes, anthology byte facts and profile, tool observations, and the clean-Linux plan. `reports/source-doctor.json` owns source-derived counts and ranges once generated. This ledger does not repeat those values.

The common access date is 2026-08-02. On that date, the local anthology was verified and every retained reference response was acquired and verified. A source-lock reference means the matching `[[references.reference]]` entry in `inputs/source-lock.toml`.
